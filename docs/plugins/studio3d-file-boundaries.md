# Файловые границы 3D

Первое открытие библиотеки закрепляет ближайшего существующего canonical родителя
до создания каталогов. Недостающие компоненты создаются по одному через его
`/proc/self/fd`, после чего следующий каталог открывается с `O_NOFOLLOW`.
Identity проверяется до и после await; окончательный canonical root должен совпасть
с именем, захваченным настройками, до первого flock и записи marker/UUID.
Подмена родителя ссылкой отзывает подготовку и не создаёт библиотеку в новом target.
Имена папок `.models` и `a..b` сохраняют допустимость: правила имён файлов модели
не ограничивают имена самой библиотеки. Смена исходного settings alias во время
подготовки также требует нового подтверждённого действия.

Бесплатный upload держит подтверждённый fd открытым до ответа. Blob читает
`/proc/self/fd/<fd>`, исходный basename передаётся отдельно; проверка до/после
запроса не позволяет закрепить token под SHA изменённого файла. Подмена пути
во время запроса не читает байты нового inode. Canonical root нельзя заменить
symlink перед новой операцией: это не выдаёт права на новый каталог.

`safePath.ts` проверяет basename, canonical root и inode открытого файла.
Чтение и SHA продолжаются с одного дескриптора; обычный файл с несколькими
hardlink и конечный symlink отвергаются. Ревизия включает inode, размер,
наносекундные mtime и ctime. Правка source во время copy отменяет публикацию.

Каталог назначения закрепляется отдельным fd. Temporary создаётся в нём через
`/proc/self/fd`; перед публикацией проверяются путь и identity каталога.
Copy создаёт независимый inode. Публикация без overwrite использует link,
поэтому две конкурентные записи создают только один результат. Собственный
temporary удаляется, данные и каталог синхронизируются через fsync.

Замена пользовательского файла требует expectedSha256 под замком назначения.
Хеш сверяется после копирования перед заменой; новая правка человека сохраняется
и возвращает changed. Внутренняя замена собственных JSON выделена отдельной
опцией, которая не является параметром пользовательского API.
