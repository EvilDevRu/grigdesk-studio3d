# Импорт и история 3D

Импорт получает доверенные корни репозиториев проектов и GrigDesk от сервера. Он
читает только `task.json` до 1 МиБ и соседние модели/картинки. Ссылки, служебные
хранилища, переписка, credentials и домашние папки инструментов исключены. Лимиты:
глубина 8, 50 000 записей на корень и 20 секунд всего обхода. Неполный результат
содержит `partial` и причины, отказ одной записи не останавливает остальные.

Сначала собираются записи и независимые файлы, затем строится DAG по task ID.
Дубликат дополняет `remote`, поздний родитель восстанавливает связь; старые проекции
удаляются после публикации новых, если человек не менял метаданные, превью или savedTo.
Изменённая модель остаётся вместе с причиной в результате скана. Индекс хранит
первоначальные метаданные и SHA превью для такого сравнения. Цикл или отсутствующий родитель даёт
предупреждение.
Одного preview недостаточно для `ready`. GLB анализируется в ограниченном процессе.
Проверка скелета дополняет родительскую версию, отдельную версию не создаёт.

Индекс `.jobs/imports-index.json` сохраняет накопленные наблюдения, планы identity,
расходы и tombstones отдельно от модели. Scan, history и ручной импорт используют
один замок. Автоимпорт не возвращает удалённую модель; явное «Забрать» разрешено.
При найденных на диске файлах CDN не требуется. История с коротким ответом не стирает
старые строки, её сумма обозначается «по известным заказам», с `partial`.

Параметры скелета сохраняются из проверенных полей, неизвестная версия не получает
подставленный набор движений. Disk запись без account provenance не даёт native прав
текущему ключу. История и poll используют фиксированный снимок доступа; смена аккаунта
во время ответа исключает перенос наблюдения. Ключи и токены не сохраняются в params.
Известные task IDs журнала раздела исключаются из повторного учёта внешней истории;
расходы разных единиц выводятся отдельными группами.

Явный импорт подтверждает доступ бесплатным poll и может докачать запись с диска
без account provenance. Этот допуск действует только для текущего скачивания и не
делает disk версию native для платных операций. Повтор partial download проверяет
уже зарегистрированные файлы и дополняет недостающие; orphan после сбоя metadata
принимается только с совпавшим SHA. Внешние строки выдаются для текущего аккаунта.

Неделя разделяет actual внутри и вне раздела, оценки, возвраты, неизвестные суммы
и текущий резерв активных заказов. Наблюдение без даты списания остаётся видимым,
но исключается из точного недельного итога с partial. Будущие даты также не входят
в прошедшие семь дней. Резерв старого активного заказа не становится недельным расходом.

Родство скелета и движений распознаётся из input.original_model_id и старого input.input.
Автоскан отмечает diskScanned в индексе под общим замком: после перезапуска обход не
повторяется. Ручной scan работает независимо от отметки. Успешное копирование CDN-файлов
в версию удаляет их временную папку .jobs/imports. Кириллица и пробелы допустимы у
соседних файлов; внутри версии имя переименовывается по роли и расширению.
