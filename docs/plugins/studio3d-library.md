# Библиотека 3D

Путь по умолчанию передаёт ядро через `core.environment().defaultLibraryDir`:
в текущем ядре это каталог `3d` в общем хранилище данных. Переменная
`GRIGDESK_3D_DIR` ядра может задать другое расположение; сохранённая настройка
`pluginSettings.studio3d.libraryDir` имеет прежний приоритет. Плагин не переносит
файлы и не меняет UUID при обновлении, выключении или переустановке. Пробные
запуски используют отдельные временные каталоги.

`.library.json` содержит schema 1 и постоянный UUID. `.owner.lock` удерживается
kernel flock одного процесса всё время жизни библиотеки и не удаляется при close.
Потеря identity замка закрывает мутации. Конструктор не имеет файловых эффектов;
открытие требует явного ensure. `.jobs` и `.uploads` отделены от папок моделей.

Модель хранится в `<slug>-<hex>/model.json`, версия — в
`v<seq>-<operation>-<hex>/version.json`. Seq и коллизии выделяются под lock модели,
JSON имеет закрытую schema. Родитель и основная версия принадлежат одной модели;
циклы, неизвестные версии и файлы вне manifest отвергаются. Manifest включает
file ID, роль, безопасное имя, размер и SHA-256. Чтение подтверждает содержимое,
а кеш SHA связан с полной ревизией inode. Приватные поля accountKey/pool не попадают
в явную проекцию DTO.

Updater версии читает актуальный JSON внутри lock. Параллельные изменения не
теряют независимые поля. Совпадающий patch возвращает прочитанную версию без изменения
updatedAt и fsync; восстановление не переписывает готовые проекции. Основная версия переключается долговечно
перед удалением
её папки: отказ записи сохраняет текущую версию. Удаление модели оставляет журнал
заказов и расходы. Active/unknown версии и входы под lease нельзя удалить или
облегчить. Облегчение убирает только model/base-model, сохраняет превью и метаданные;
для основной версии требуется force.

Учёт размера включает скрытые входы заданий, uploads, partial и JSON. Это логические
байты, а не обещание освобождения физических блоков reflink. Broken папка выделяется
в отдельный список. Incoming перечисляет обычные 3D файлы; импорт должен проверить
их формат до создания версии. Уборка старых uploads уважает действующие leases.

## Metadata и состояния

Model JSON хранит schema/id/name, project/category/tags/notes, даты, основную версию
и происхождение. Version JSON хранит id/seq/parent/kind/operation/label/provider,
нормализованные params, status/progress/eta/error/waitReason, task/check/native identity,
files/mainFileId/views, stats, cost и savedTo. Cost различает estimated, actual, free,
единицу исполнителя и состояние; расходы модели вычисляются из сохранённого журнала,
а не количества файлов или текущего дерева версий.

Статусы отражают очередь, отправку, неизвестный исход, генерацию/скачивание,
готовность, отказ, unresolved и облегчённую версию. Remote task не означает наличие
скачанного файла. Unknown не даёт автоматический paid retry; unresolved сохраняет
платёжное наблюдение после явного закрытия строки заказа. Main выбирается только из
готовых файлов по manifest. Статистика отсутствующего/повреждённого формата остаётся
неизвестной; тяжёлый GLB анализируется отдельным ограниченным процессом.

Settings JSON хранит saveFolders отдельно по project/repo. `.jobs` содержит durable
intents, независимые inputs и batch snapshots, `.jobs/imports-index.json` — наблюдения/планы
импорта и tombstones. Скан диска имеет лимиты времени/глубины/числа entries, порядок
родитель→потомок; происхождение, цена и native параметры берутся только из проверенных
полей. История usage дополняет наблюдения и отмечает неполноту; autoImport не воскрешает
удалённую человеком модель. Явный импорт может создать её снова.

«Облегчить» не превращает неизвестную стоимость в ноль и не снимает provenance
метаданных. Временные inputs/uploads и скачанные partial входят в учёт логического
размера. Уборка старых снимков не удаляет active/unknown входы или чужие файлы модели.

Incoming и сохранение в проект принимают внешние имена с кириллицей и пробелами,
запрещая разделители, .., управляющие символы и начальную точку. Manifest версии
продолжает использовать латинское имя. Подсчёт размера пропускает исчезнувший tmp;
разовый отказ подсчёта не отзывает допуск, потеря identity библиотеки по-прежнему отзывает.


Пути проверяются по явному `environment.protectedDirs`, `userPluginsDir`, каталогу
пакета и собственной ESM generation. Пересечение запрещено в обе стороны,
lexical и canonical, включая отсутствующего потомка symlink; проверка предшествует
mkdir/marker/flock и записи prefs. Уже сохранённый опасный путь даёт видимый отказ:
данные остаются на месте, автоматического выбора пустой библиотеки нет.

Disable закрывает новый admission, но принятые jobs и file leases завершаются.
После их освобождения callback проверяет тот же context/generation под admission
lock и закрывает idle library без polling timer. Unknown удерживает owner и причину
занятости. Повторное включение заново открывает ту же допустимую библиотеку и UUID.
