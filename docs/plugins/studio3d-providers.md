# Исполнители раздела 3D

Узкий адаптер объявляет `type: '3d'` и capability `studio3d`. Реестр раздела
берёт только такие адаптеры, затем добавляет встроенного исполнителя «Локально».
Универсальные чатовые исполнители и карточки без capability не входят в список.
Tripo сохраняет чтение кредитов и не получает чатовый transport.

Предложения соединяют общий словарь действий с объявлением исполнителя.
Цена по умолчанию вычисляется из нормализованных полей; отсутствие ключа оставляет
предложения видимыми с причиной и переходом в настройки. Бесплатные локальные
поворот/масштаб используют то же объявление. Масштаб недоступен без достоверной высоты.

Native task относится к самой версии, текущему аккаунту и объявленному типу.
Бесплатный preflight проверяет сохранённый номер до предложения native-only шага.
Истёкший номер не запрещает действие с файловым fallback. Локальный поворот или
масштаб не наследует native от предка. Без проверенных параметров версии/типа
скелета список движений пуст и содержит причину, а не запасной human/v1 набор.

Общие ключи и адаптеры поставщиков принадлежат ядру. Плагин получает их через
core.getProviders('3d'); opaque snapshot передаётся тем же объектом. Ошибка
поставщика распознаётся структурно по закрытому kind/submitted, без instanceof
между ESM-копиями. Значение submitted допускает только true/false/null.

Протокол Tripo, ключи и общие каталоги остаются в соответствующем выпуске ядра.
Их исходная документация — `docs/grigdesk/plugins/tripo-api.md` и
`docs/grigdesk/plugins/tripo-module-boundaries.md` в дереве GrigDesk. Это общие
контракты поставщика; они не копируются в продуктовый пакет. Относительных ссылок
на соседний checkout ядра в переносимом выпуске нет.
