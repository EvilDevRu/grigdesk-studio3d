# Поиск и расходы моделей 3D

Поиск нормализует регистр, ё/е, знак # и пробелы. Каждое слово должно найтись
в общем тексте модели и версий: имена, теги, заметки, проект, категория, действия,
prompt/negative_prompt/hint, номера задач, файлы и сохранённые имена. Фильтры
проекта, категории, происхождения, исполнителя, периода и каждого has пересекаются.
Total считается до среза, размер страницы ограничен 200. Сортировка стабильна по id.

Сводка считает active включая unknown, флаги скелета/анимации/частей/картинок,
логические байты manifest. Preview берётся из основной версии, иначе последней
готовой версии с preview. Цена estimated не становится actual при отсутствии
подтверждения. Расходы группируются по исполнителю и единице: actual, estimated,
известный refund, число неизвестных исходов и их оценка. Разные единицы не
получают общую spent сумму. Бесплатные локальные шаги не добавляют расходы.
