# Модули формы создания 3D

`CreatePanel.vue` владеет черновиком экземпляра, вычисляемыми предложением, входами и
отпечатками, общими `error` и `alive`, а также watchers и lifecycle hooks. Шаблон формы
связывает прежние поля, PriceButton, виды и нарезку листа с обработчиками модулей.

| Модуль | Владение и граница |
| --- | --- |
| `creationRequest.ts` | Чистые строки prompt, предел 50, строки пачки и JSON-копия одиночного запроса |
| `useCreationInputs.ts` | Файлы, один uploading ref, кэш File, поколение входа, preview URL |
| `useCreationQuote.ts` | Поколения offers/quote и таймер пачки; использует общие refs формы |
| `useCreationForm.ts` | Черновики действий и подтверждение запуска через getter отпечатка |

Порядок watchers: черновики, предложения, расчёт, файлы видов, библиотека, режим.
Первые три запускаются сразу. При размонтировании SFC сначала снимает `alive`, затем
освобождает входы, отзывает поколения предложений и расчёта и очищает таймер пачки.
Модули сами не регистрируют watch или lifecycle hooks и не создают подписок SSE.

Одиночный расчёт использует debounce store; собственные 300 мс формы принадлежат
только batchQuote. Изменение формы сразу очищает цену. Price_changed показывает новый
расчёт и требует нового нажатия, без автоматической повторной оплаты.

После согласия в диалоге пачки ещё раз проверяются жизнь и активность формы и текущий
отпечаток. Правка, скрытие или размонтирование во время подтверждения дают ноль POST.
Неизменённая форма передаёт исходный UUID кнопки и копию server snapshot одному batchRun.

Тесты модулей вызывают обработчики напрямую. Component tests используют настоящие
модули и подменяют только внешние API, store и диалог. Декодер изображений входов —
узкий порт, позволяющий проверять освобождение bitmap и URL без браузерного декодера.

`uiContext.ts` захватывает private AbortSignal текущего UI. После await проверяются
его жизнь и identity нового injected context, даже когда marker библиотеки совпадает.
Batch после смены context не отправляется; поздний success service может законно снять
сохранённое намерение, но не вызывает onCreated нового UI. UI token не записывается
в durable request/fingerprint и не создаёт новый UUID при переподключении.

Rebind отзывает локальные uploads и оба поколения расчёта, сохраняя введённые данные,
имена/preview и уже готовые identity той же библиотеки. Список проектов получает
отдельное чтение B; поздний A не заменяет options и не удерживает loading.
