# Библиотека и действия модели

Библиотека использует server search с задержкой 300мс и отдельными фильтрами проекта,
категории, происхождения, исполнителя и содержимого. Пагинация продолжает тот же
снимок поиска. Карточки и строки дерева используют общие UI controls; дерево показывает
родителя перед потомками, основную версию и прогресс активных заказов.

«Доработать модель» берёт группы, поля, доступность и цены из offers. Недоступное предложение
остаётся видимым с причиной. Новый шаг фиксирует исходную versionId, нормализованные
значения и подтверждённую цену в durable намерении. Unknown и unresolved не имеют
кнопки новой оплаты; повтор разрешён только по серверному retryAvailable с новой ценой.

Сохранение бесплатно копирует родной файл в выбранный server repository. Другой формат
открывает шаг «Экспорт». Деталь модели содержит необязательный закрытый saveFolders:
проект → ключ репозитория → относительная папка из settings библиотеки. Старый ответ
без этого поля не является сохранённым значением. Конфликт exists показывает SHA файла;
изменение после вопроса требует нового подтверждения changed. Ожидающая форма не
продолжает сохранение после смены модели, библиотеки или закрытия окна.

«Спросить агента» сначала вызывает штатный workdir preview с папкой из server DTO.
Capability и фактический cwd должны подтвердить выбранный корень. Затем создаётся
черновик с абсолютным путём версии, сводкой и incoming в той же папке. Проект остаётся
контекстом: prompt не добавляет roots. Рабочая папка задаётся явно, включая библиотеку
вне GrigDesk и модель без проекта. Черновик не отправляется автоматически.

Incoming добавляется отдельной файловой версией. Удаление и облегчение подтверждаются
общим диалогом, основная версия требует force. Наличие потомков даёт понятный отказ
без каскадного удаления. Сравнение выбирает второй зарегистрированный файл.

Проверки: studio3d-library.component, studio3d-model.component, studio3d-api и штатный
workdir resolver с изолированными каталогами.

Расширение имени при бесплатном сохранении должно совпадать с готовым файлом. Сервер
возвращает format_requires_export до создания папки/копии при попытке назвать GLB
как STL/FBX/OBJ. Выбор другого формата остаётся отдельным платным шагом «Экспорт».

Проверка скелета отображается отдельно от готовности версии: pending, разрешённый
тип тела, отказ или ошибка. Ответ проверки без новой версии сохраняет прежний выбор.
ModelEditDialog меняет имя, категорию и проект; удаление всей модели требует отдельного
confirmDialog. Параметры и типы облачных задач получают человеческие подписи.
