# Задачи 3D и неизвестные исходы

Панель показывает активные, конечные за 24 часа и внешние наблюдения отдельно.
Обновление перечитывает бесплатную историю, scan выводит found/imported/skipped
и причины неполного обхода. Явный внешний импорт открывает возвращённую сервером модель.

Unknown и unresolved разбираются по intentId и childId, включая проверку без versionId.
Кандидат не выбирается автоматически. Можно указать номер заказа вручную; сервер проверяет
аккаунт, тип и отсутствие другого владельца. Решение подтверждается общим диалогом.
Close освобождает локальный резерв, не отменяет облачный заказ и не обещает возврат.
Поздний job другой библиотеки не разрешает решение для нового marker.

Недельный closed DTO группы содержит actual, sectionActual, externalActual, estimated,
reserved, refunded, unknownCount и unknownEstimated. Расход внутри раздела берётся из
durable intents, внешний — из уникальных наблюдений. Записи без времени списания не
увеличивают точный недельный итог и делают историю неполной; они остаются во внешнем
списке. Будущие даты не относятся к прошедшим семи дням. Резерв активных старых заказов
показывается отдельно, включая заказ старше недели.

Reserved не является неизвестным списанием. State показывает доступный баланс с
учётом ещё не отражённых локальных резервов; уже frozen кредиты поставщика не вычитаются
повторно. Подтверждённое списание имеет приоритет над прежней оценкой. Валютные группы
не складываются друг с другом; partial означает счёт только по известным заказам.

Проверки: studio3d-tasks.component, studio3d-api, studio3d-jobs, studio3d-importer,
studio3d-search и закрытые contracts.

Неотправленная waiting-позиция имеет «Отменить» с подтверждением отсутствия оплаты.
После суток ожидания денег сервер закрывает её сам. Три пропуска принятой задачи
открывают ручной разбор: close переводит её в unresolved с неизвестным списанием
и освобождает пул, сохраняя возможность позднего связывания.
