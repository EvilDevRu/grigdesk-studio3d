# Просмотр моделей 3D

`ModelViewer.vue` использует публичный порт `viewerEngine.ts`. Three и addons загружаются
динамически из `engine.ts`; Vue хранит строки, числа и DTO, а не renderer или сцены.
Настоящие GLTFLoader с MeshoptDecoder, FBXLoader, OBJLoader и STLLoader разбирают файлы.
Splat показывает ограниченное облако точек с явной подписью; гауссианы не отрисовываются.

Панель предоставляет текстуры, глину, сетку, кости, части, фон, свет, вписывание,
fullscreen и WebP снимок. AnimationMixer меняет реальную позу, выбор клипа, пауза,
время и скорость 0,5–2× доступны через UI. Два холста сравнения обмениваются камерой
без обратного цикла событий. «Убрать сравнение» освобождает второй холст; отказ его
загрузки сохраняет первую модель, её controls и возможность снимка. Геометрия определяет размер кадра;
предположение о
направлении модели не вызывает автоматический разворот.

## Ресурсы и пределы

Источник принадлежит одной версии библиотеки или папке scoped viewer token. URI
проверяется до сети: чужой origin/API, protocol-relative/file URI, traversal,
закодированные separators и вложенное кодирование запрещены. Ресурсы соседнего glTF
скачиваются один раз с ограничением фактического потока, затем загрузчик получает
Blob, принадлежащий текущему разбору. Data URI разрешены только для PNG/JPEG/WebP
и buffers с ограничением до decode. Все объявленные URI проверяются, включая
неиспользуемые сценой. Draco, KTX2, архивы и OBJ с MTL дают явный отказ.

Модель ограничена 150 МиБ, JSON — 16 МиБ; граф glTF проверяется на цикл, некорректные
ссылки и глубину 256. Растровая текстура ограничена 20 МиБ/64 Мп до создания bitmap.
Binary FBX проверяет node/property offsets, число и объём массивов; compressed массив
сначала проверяется потоковым deflate без накопления распакованного результата.
Необработанная внешняя текстура FBX не получает сетевой запрос addon.
Консервативная оценка bytes/decode/RAM/GPU двух панелей имеет общий бюджет 1024 МиБ;
готовая геометрия дополнительно ограничена пятью миллионами треугольников.

Src получает AbortController и поколение. Поздняя сцена, progress или snapshot не
публикуются в новую модель. Dispose снимает RAF, controls, callbacks, listeners,
mixers, geometry/materials/textures, закрывает ImageBitmap, отзывает ObjectURL и
освобождает WebGL context. Скрытый viewer приостанавливает RAF. Context loss показывает
управляемую ошибку с предложением закрыть и открыть просмотр снова и ссылкой на файл.

## Снимок версии

Просмотрщик живёт только внутри раздела «3D»: чат, «Код» и окно документов модели не
открывают. ModelPage впервые снимает preview версии без картинки. Handler захватывает точную
library/model/version и отзывает поздний кадр после смены страницы. Общий viewer не
загружает снимок в чужую версию автоматически.

## Проверка

Node fixtures проверяют настоящие parsers, meshopt, skin/parts, FBX и splat, граф и
URI guards. Component tests подменяют только engine port и проверяют controls,
устаревшие load/snapshot, ошибку сравнения без закрытия первой модели и dispose.
Тест движка открывает две сцены по 300 МиБ расчётного резерва и проверяет возврат
общего счётчика памяти к нулю после dispose. Эти проверки не являются ручной проверкой
пикселей или живого WebGL в браузере.

ResourcePolicy получает обязательный ownApiPrefix `/api/ext/studio3d` из session API.
Prefix проверяется точно с границей `/`, token/version regex применяется к suffix.
ViewerLoading и offline parser fallback используют тот же prefix. Другой plugin,
старый API, чужой token/version и double encoding отклоняются до сети.
